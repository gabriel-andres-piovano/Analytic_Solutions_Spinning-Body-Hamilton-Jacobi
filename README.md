# Analytic_Solutions_Spinning-Body-Hamilton-Jacobi
Code for the computation of the analytic solutions for the nearly-equatorial motion of a spinning test-particle in Kerr spacetime. The
Companion repo of "Piovano" arXiv: ()

Mathematica files
- ```AnalyticSpinOrbitsHamiltonJacobi.wl```: package for the calculation of the analytic spin-corrections to periodic and homoclinic orbits for the nearly equatorial motion.
- ```SpinOrbitsHamiltonJacobi.wl```: package for the numerical spin-correction to generic periodic orbit. Developed in https://github.com/gabriel-andres-piovano/Spinning-Body-Hamilton-Jacobi
- ```Spin_corrections_to_orbits_near_equatorial_motion.nb```: presents the functions available in the package ```AnalyticSpinOrbitsHamiltonJacobi.wl```
